# Authorship and contribution

## The authorship draft

Preserve the returned authorship draft from compose/integrate locally. It is a partial single-request history, NOT consent or approval. When combining drafts, give revisions unique ids, link parents to the actual previous revision, retain its original scene/assets/cause, and retain rejected branches. A before snapshot only knows the current request's scene, not historical geometry. Record actual developer feedback as human; your own suggestions as agent. For take verdicts, copy sha256 from the vendored asset lock; a clip name or sampleId is not an exact byte identity. Statements use the parsed statementIndex within the named script revision; take targets use clipPath+sha256 instead. Gameplay recording is not required.

## Contribution

Optional authorship contribution: satie_record_authorship { journal } previews sanitized intent, revisions and labels without storage. Show the preview to the developer: URI stripping is not anonymity. Only after explicit consent call again with mode=contribute, consent=true and reviewedContentHash from that unchanged preview. Never invent human feedback or infer keep from a successful build. Realism is advice, not an authoring gate; preserve surreal/stylized intent. This contribution is separate from satie_record_episode and from measured acoustic evidence.
